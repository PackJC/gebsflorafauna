# Changelog

## 2.0.0

Geb's Flora & Fauna is now three mods, so a server can run the parts it wants: **Geb's Animals** (this one), [Geb's Plants](https://github.com/PackJC/gebsplants) and [Geb's Mushrooms](https://github.com/PackJC/gebsmushrooms). Classnames are unchanged.

Server owners: a server that ran Geb's Flora & Fauna should load all three to keep every item players already have. Leaving one out deletes its items from the server's storage at the next restart.

### Added
- **Panda bear** (`geb_Pandabear`).
- Every string translated into all 13 languages: Czech, German, Russian, Polish, Hungarian, Italian, Spanish, French, Chinese (Traditional and Simplified), Japanese and Portuguese.
- A website with every animal, the server setup and a searchable classname list: [packjc.github.io/gebsanimals](https://packjc.github.io/gebsanimals/).

### Changed
- Renamed from Geb's Flora & Fauna (`gebsflorafauna`) to Geb's Animals (`gebsanimals`). The garden crops, wild ginseng and fungi moved to Geb's Plants and Geb's Mushrooms.
- Every animal is re-rigged to the vanilla skeleton it animates with, so it moves like the animal it's based on.
- The camel, both turkeys and the penguin have rebuilt models, the chimpanzee has fur, and the alien is green.
- New mod logo in the same style as Geb's other mods: the deer, white in a black frame and red when hovered. It now shows in the launcher.

### Fixed
- The server and client logs no longer show "ANIMATION (E): Can't load …/Anims/cfg/skeletons.anim.xml" on every start.

## 1.x (Geb's Flora & Fauna, 2022–2025)

The original mod: the wildlife, their meat and pelts, the coonskin cap and the turkey recipe, with a first set of crops and mushrooms. Its full history is in this repository's commit log.
